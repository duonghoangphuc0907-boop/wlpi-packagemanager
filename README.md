# wlpi-packagemanager
**What is wlpi?**

CLI lightweight Windows package manager written in Python.

**How to run wlpi on command without the directory**

Press Win + R

Type sysdm.cpl

Navigate to Advanced

Click Enviroment Variables...

Under System variables, click Path

Select Edit

Select New

Enter the directory that you placed earlier.

**Wlpi stand for**

Windows Lightweight Package Installer
